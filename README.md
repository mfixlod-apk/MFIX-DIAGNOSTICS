# MFIX Diagnostics

מערכת Web/PWA לבדיקות ואבחון מכשירי Android ו-iPhone במעבדת סלולר.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בנייה

```bash
npm run build
npm run preview
```

## פריסה

הפרויקט מוגדר ל-GitHub Pages תחת הנתיב `/MFIX-DIAGNOSTICS/`. Workflow אוטומטי נמצא ב-`.github/workflows/deploy.yml`.

## מגבלות חשובות

- דפדפני iOS ו-Android אינם חושפים לכל אפליקציית Web את כל בדיקות החומרה. בדיקות חסומות מוצגות כלא נתמכות או כבדיקה ידנית.
- צבעי המסך, מגע, מצלמה, מיקרופון ושמע דורשים אישור מפורש של הטכנאי.
- היסטוריית הבדיקות נשמרת מקומית בדפדפן ואינה מסונכרנת לשרת.
- אין כאן אבחון אוטומטי של תקינות רכיב פיזי, IMEI, סוללה או שקע טעינה.
